 How to Open in Terminal

### Windows
1. **Right-click**: Right-click empty space in the folder and select



 **Open in Terminal**.

cmd command -1  npm install  press **Enter**.  install all the dependencies 


             2  npm run dev`  press **Enter**.


2. **Address Bar**: Click the address bar, type `cmd` or `powershell`, and press **Enter**.

 using `npm install` install all the dependencies 
 using `npm run dev` start the development server

3. **VS Code**: Press `Ctrl + ~` (tilde) to open the terminal inside the editor.
